# 🌐 Personal Portfolio Website

This is my personal portfolio website showcasing my projects, skills, resume, and contact information.

🔗 **Live Site**: [https://personal-portfolio-blush-one.vercel.app/](https://personal-portfolio-blush-one.vercel.app/)

---


## ✨ Features 

-  Stylish and responsive user interface  
-  Smooth scroll navigation  
-  Projects section with GitHub links  
-  About Me and Skills sections  
-  Contact form  
-  Footer with social media links  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Hosting:** Vercel
